ENG: Deep Learning-Based Real-Time Student Behavior Analysis and Attention Loss Detection
Description: This study aim to construct a strong deep learning-based real-time student behavior analysis system particularly meant for spotting attention loss during learning sessions. The cameras positioned in classrooms will be used in this system to record and examine minute cues of student focus, distraction, and comprehension. Key visual indicators of student engagement and disengagement will be identified via advanced deep neural network architectures e.g., Convolutional Neural Networks, Recurrent Neural Networks, Transformers. Overall body language (e.g., fidgeting, leaning forward/backward), head pose (e.g., looking away, nodding), gaze direction (e.g., staring at the instructor, looking at distractions), and facial expressions (e.g., boredom, perplexity, curiosity) are among these markers. The project will give teachers/professors a dynamic dashboard showing real-time analytics and alerts so enabling quick interventions to improve learning results. The instructor can use attention loss signs as vital real-time feedback to activate adaptive teaching techniques and interactive interventions meant to re-engage students. The main objective is to design a helpful learning tool that respects ethical issues and privacy, so enabling an environment whereby technology improves instruction and learning without invading personal space.
